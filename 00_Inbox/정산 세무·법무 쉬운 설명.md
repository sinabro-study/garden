# 정산 세무·법무 쉬운 설명
- 기준 문서: [[정산 시스템 구축 가이드]] 10장 (세무·법무 고려사항)
- 대상: 세무·법 지식이 없는 구성원 — 정산 시스템 논의에 참여하기 위한 최소한의 배경 지식
- 핵심 한 줄: 남에게 돈을 지급하는 순간, 세금 신고 의무와 법적 규제가 자동으로 따라옴

## 1. 부가가치세 (VAT)
| 질문 | 답 |
| --- | --- |
| 뭔가요? | 물건·서비스 가격에 붙는 10% 세금 — 편의점 영수증의 "부가세"와 동일 |
| 누가 내나요? | 최종 소비자가 부담하고, 사업자는 걷어서 국가에 대신 납부 |
| 정산과 무슨 상관? | 플랫폼 수수료도 "서비스"라서 부가세 10%가 붙음 |
- 예시: 수수료가 1,000원이면 파트너에게 실제 청구되는 금액은 1,100원 (수수료 1,000 + 부가세 100)
- 시스템이 공급가액(1,000)과 부가세(100)를 분리 저장하는 이유: 세금계산서 발행과 부가세 신고의 근거 금액이 다르기 때문

## 2. 세금계산서
| 질문 | 답 |
| --- | --- |
| 뭔가요? | 사업자 간 거래의 공식 영수증 — 국세청에 전자로 신고되는 증빙 |
| 왜 필요? | 이게 있어야 양쪽 모두 세금 신고 시 매출·비용으로 인정받음 |
| 정발행 vs 역발행? | 발행 버튼을 누구가 누르냐의 차이 |
- 정발행: 판 사람이 발행 — 수수료를 "파는" 플랫폼이 파트너에게 발행 (원칙적 방식)
- 역발행: 사는 쪽이 대신 작성하고 판 사람이 승인만 — 파트너가 수천 곳인 플랫폼에서 대량 처리를 위해 흔히 사용
- 어느 쪽이든 시스템이 회차별 수수료 금액을 정확히 산출해줘야 발행 가능 — 정산 시스템이 세금계산서의 원천 데이터

## 3. 원천징수
| 질문 | 답 |
| --- | --- |
| 뭔가요? | 돈을 주는 쪽이 받는 사람의 세금을 미리 떼서 국가에 대신 내는 제도 |
| 익숙한 예? | 월급명세서의 소득세 공제 — 회사가 미리 떼서 납부하는 것과 동일한 구조 |
| 왜 존재? | 개인은 세금 신고를 누락하기 쉬우므로, 지급하는 쪽(회사)에 의무를 지움 |
- 정산 맥락: 파트너가 개인(프리랜서·비사업자)이면 지급액에서 3.3%를 떼고 지급해야 함
- 법인·개인사업자에게는 떼지 않음 — 그들은 스스로 신고·납부하는 주체이기 때문
- 그래서 시스템이 파트너의 사업자 유형(법인/개인사업자/개인)을 반드시 관리해야 함
- 부속 의무: 뗀 세금은 다음 달 10일까지 신고·납부하고, "누구에게 얼마 지급했다"는 지급명세서도 국세청에 제출

## 4. PG업·에스크로 등록 (전자금융거래법)
| 질문 | 답 |
| --- | --- |
| 뭔가요? | 남의 돈을 중간에서 받아 전달하는 사업을 하려면 금융당국 등록이 필요하다는 규제 |
| 왜 존재? | 중간 사업자가 돈을 들고 도산·유용하면 소비자·판매자가 피해를 보기 때문 |
| 정산과 무슨 상관? | 구매자 돈을 우리가 받아뒀다가 파트너에게 지급하는 구조 = "남의 돈 보관·전달"에 해당할 수 있음 |
- 사업 구조에 따라 등록 대상 여부가 갈리므로 반드시 법무 검토 필요 (임의 판단 금지)
- 미등록 상태로 해당 영업을 하면 형사 처벌 대상이 될 수 있음 — 정산 구조 설계 단계에서 확인해야 하는 이유

## 5. 자금 분리
- 원칙: 파트너에게 줄 정산 대금과 회사 운영 자금의 계좌를 분리할 것
- 이유: 한 통장에 섞이면 회사 자금 사정이 나빠졌을 때 파트너 돈이 먼저 위험해짐
- 효과: 파트너 신뢰 확보 + 회계 감사·잔액 대사가 명확해짐

## 6. 개인정보 (계좌·주민등록번호)
- 계좌번호·주민번호는 개인정보보호법이 특별히 보호하는 정보 — "필요하니까 수집"이 아니라 수집 근거가 있어야 함
- 지켜야 할 것 3가지
  - 수집 근거: 원천징수 신고 등 법적 의무 이행 목적 명시
  - 보관: 암호화 저장, 화면에는 마스킹(예: 110-***-****789)
  - 파기: 보관 기간이 끝나면 삭제 — 계약 종료 후 무기한 보관 금지

## 7. 한눈 요약
| 항목 | 한 줄 요약 | 어기면 |
| --- | --- | --- |
| 부가세 | 수수료에 10% 붙여서 청구·신고 | 가산세 |
| 세금계산서 | 수수료 거래의 공식 영수증 발행 | 가산세, 파트너 비용 인정 불가 |
| 원천징수 | 개인에게 지급 시 3.3% 떼고 대신 납부 | 가산세 + 미납 세액 회사 부담 |
| PG/에스크로 | 남의 돈 중개는 등록 필요 — 법무 검토 필수 | 형사 처벌 가능 |
| 자금 분리 | 파트너 돈과 회사 돈 통장 분리 | 파트너 자금 손실 위험, 신뢰 붕괴 |
| 개인정보 | 계좌·주민번호는 근거 있게 수집·암호화·파기 | 과징금, 유출 사고 시 법적 책임 |
