# 1주차 마지막 회상 복습 · Java 실행과 주문 계산

## 목표

- 자료를 다시 보지 않고 1주차 핵심 흐름을 자기 말로 설명한다.
- 컴파일과 실행, 배열 참조, 반복, 배송비 분기를 주문 계산에 연결한다.

## 회상할 흐름

Java 소스를 수정한 뒤에는 `javac`로 `.class`를 다시 만들고 `java`로 실행한다.
배열을 다른 변수에 대입하면 두 변수가 같은 배열을 가리킬 수 있다.
반복문은 인덱스가 배열 길이보다 작은 동안 요소를 읽고 합계를 누적한다.
상품 합계가 기준 이상이면 배송비 0원, 기준 미만이면 배송비 2,500원을 적용한다.

## 회상 문제

자료를 보지 않고 세 문항을 한 번에 답한다. 정답과 해설은 답변 후 기록한다.

1. `OrderCalculator.java`의 숫자를 바꾼 직후 변경된 결과를 보려면 어떤 두 명령을 순서대로 실행해야 하는가? 각 명령의 역할도 한 문장씩 설명한다.
2. `int[] items = {4000, 6000}; int[] alias = items; alias[1] = 7000; alias = new int[]{9000};`을 실행했다. 마지막에 `items[1]`은 얼마인가? 두 번의 `alias` 사용이 원래 배열에 각각 어떤 영향을 주는지 설명한다.
3. 항목 금액이 `{9000, 16000}`일 때 반복문에서 읽는 금액과 누적값을 순서대로 적는다. 상품 합계, 배송비, 최종 총액과 배송비 조건 `subtotal >= 25000`의 참·거짓을 설명한다.

주문 금액 계산기의 직접 실행과 터미널 출력 확인은 학습자 요청으로 생략했다. 따라서 이 복습은 개념 이해를 확인하며 실습 재현은 평가하지 않는다.
