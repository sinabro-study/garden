# 면접 준비 학습 허브

목표: 이력서와 포트폴리오에 적은 모든 직접 구현 경험을 Level 5까지 설명하고 검증한다.  
주변 기술도 프로젝트에 연결해 Level 5 질문까지 연습하되 실제 수행하지 않은 일은 수행했다고 답하지 않는다.

## 진행 규칙

1. `01_학습_로드맵.md`의 순서대로 한 단원씩 진행한다.
2. 단원마다 Level 1(정의) → 2(동작) → 3(장애·한계) → 4(대안·Trade-off) → 5(실제 적용·검증) 순서로 답한다.
3. 먼저 자료를 보지 않고 2분 이내 구술 답변을 작성한다.  
   이후 근거 자료와 대조해 수정한다.
4. Level 5에는 본인 역할·당시 조건·선택 이유·재현과 검증 방법·수치의 분모와 기간·남은 한계를 반드시 포함한다.
5. 증빙이 없으면 `미확인`으로 남긴다.  
   추정 답변을 실제 운영 사실처럼 바꾸지 않는다.
6. 각 세션 종료 시 `03_학습_기록.md`에 날짜·답변 수준·틀린 점·다음 행동을 남긴다.  
   다섯 Level 모두 통과해야 다음 단원으로 이동한다.

## 통과 기준

각 Level에 대해 정확성·사례 연결·반문 대응을 각각 0~2점으로 평가한다.  
Level별 5/6점 이상이며 중대한 사실 오류가 없어야 통과한다.  
Level 5는 증빙 출처 또는 증빙 부재를 명확히 말해야 한다.

## 개념 설명과 그림

16개 단원 각각에 **기술 개념 전체 설명 → 흐름 그림 → 사례 연결 → Level 1~5 문제 → 학습 기록**을 넣었다.  
먼저 `01_단원_01_JPA.md`부터 순서대로 읽고 답한다.  
`05_핵심개념_그림과_요약.md`는 전체 범위의 빠른 복습용이다.

식별자와 인덱스 심화 자료: [UUIDv4·UUIDv7](./17_심화_UUIDv4_UUIDv7.md) → [B-tree 인덱스](./18_심화_B_tree_인덱스.md) → [CHAR(36)·BINARY(16)](./19_심화_UUID_CHAR36_BINARY16.md).
