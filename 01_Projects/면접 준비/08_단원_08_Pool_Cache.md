# 08. 커넥션 풀·병렬 조회·캐시

## 기술 개념 전체 설명

### 커넥션 풀

풀은 DB 연결을 재사용한다.  
응답 지연은 SQL 시간뿐 아니라 풀 대기·커넥션 점유 시간도 포함한다.  
활성 연결 수·대기 수·획득 시간·DB 최대 연결 수를 함께 본다.

### 병렬 조회

독립 쿼리를 병렬로 실행하면 벽시계 시간이 줄 수 있지만 커넥션과 DB 부하가 늘어난다.  
스레드 풀·DB 풀 크기와 부분 실패를 고려한다.

### 캐시

5분 캐시는 반복 조회를 줄이지만 갱신 지연과 노드 간 불일치를 만든다.  
TTL과 무효화 방식을 정한다.  
Stampede와 캐시 미스가 DB 부하에 미치는 영향도 고려한다.
