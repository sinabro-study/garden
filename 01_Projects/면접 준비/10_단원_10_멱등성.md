# 10. 멱등키와 DB unique 제약

## 기술 개념 전체 설명

### 멱등성

같은 업무 요청이 재시도·중복 전달돼도 결과가 한 번만 반영되는 성질이다. HTTP 메서드의 일반적 멱등성과 특정 업무 명령의 멱등성은 구분한다.

### 경쟁 상태

조회 후 없으면 INSERT하는 애플리케이션 검사만으로는 동시 요청 경쟁을 막지 못한다. unique 제약을 최종 방어선으로 두고 중복 충돌을 기존 성공 결과 또는 명확한 오류로 해석한다.

### 키 설계

주문·송장별 업무 식별자, 보존 기간, 동일 키에 다른 페이로드가 들어온 경우, 처리 중 상태, 실패 후 재시도를 정의한다.

## 이력서·포트폴리오 사례 연결

OMS 주문 중복 수집·송장 중복 발행에 앱 멱등키와 DB unique를 적용해 중복 출고 0건이라고 기재했다. 관측 기간과 탐지 범위를 확인한다.
