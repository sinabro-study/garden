# 13. SLI·SLO와 Error Budget

## 기술 개념 전체 설명

### SLI와 SLO

SLI는 실제 서비스 품질을 측정한 값이다.  
SLO는 서비스가 달성하려는 목표다.  
분자·분모·제외 대상과 측정 창을 먼저 정의해야 숫자에 의미가 있다.

### 측정 기준

HTTP 5xx 가용성만 보면 2xx 안에 숨은 처리 실패를 놓친다.  
사용자 입력 4xx와 서버 오류를 구분하고 지연은 500ms 이내 응답 비율로 계산했다.

### Error Budget

목표 미달 허용량을 기간 안에서 계산한다.  
동일 요청을 오류와 지연으로 따로 셀지 또는 통합 실패로 셀지 정의한다.  
지표 정의 변경 전후는 품질 변화와 측정 변화로 나눠 해석한다.

## 이력서·포트폴리오 사례 연결

WMS 지연 98.56→98.89%는 목표 미달이며 연동 모듈 실질 성공률 99.73→99.56%는 악화됐다.  
후자의 원인과 후속 조치를 확인한다.
