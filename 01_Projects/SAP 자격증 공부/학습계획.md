## 일정과 목표

32주/160시간을 첫 계획으로 사용한다. 합격을 보장하는 기간은 아니며, 이해도에 따라 4주 단위로 늘리거나 줄인다. 지금 시작하면 2027년 6월 전후에 준비도를 평가한다. 기초 구간은 Associate 수준의 이해를 목표로 하되, 별도 자격증 응시는 선택 사항이다.

AWS가 제시하는 대상은 AWS 설계·구현 경험 2년 이상 수준이다. 초보자는 실습과 설계 연습 시간을 추가할 수 있다.

## 다음 단계로 넘어가는 기준

일반 주차: 핵심 개념을 자기 말로 설명하고, 새로운 확인 문제 5개 중 4개 이상 정답 및 선택 이유 설명. 부족하면 오개념을 보완한 뒤 새 문제로 재확인한다.
점검 주차: 새로운 문제 80% 이상과 설계 근거 설명을 학습상 목표로 한다. 이는 AWS 합격점 환산이 아니다.
응시 판단: 처음 보는 적법한 전체 모의시험 2회에서 각각 80% 이상, 크게 취약한 영역 없이 오답·대안 선택 이유를 설명할 수 있는지 확인한다. 미달이면 2~4주 보완 후 재평가한다. 모의시험 성적은 실제 합격을 보장하지 않는다.

## 이 채팅에서 진행하는 방법

“1주차 두 번째 수업 시작”, “오늘 30분만 공부할게”, “지난 내용 복습”, “오답 다시 풀기”, “진도 보여줘”처럼 요청한다.
매 수업은 개념 설명 → 예제 → 사용자가 푸는 문제 → 채점·해설 순서로 진행한다. 답변 전에는 정답을 공개하지 않는다. 제출된 답변을 근거로 진도를 갱신하며, 스스로 한 공부는 사용자 보고를 반영한다. 대화가 이어지지 않은 동안 자동으로 수업을 진행하지 않는다.

## 실습 방식

첫 수업은 계정 없이 가능하다. 실제 AWS 실습 전에는 계정 사용 가능 여부와 허용 비용을 확인하고, 생성 리소스·예상 비용·삭제 절차를 제공한다. 예산 알림은 지출을 자동 차단하지 않는다. 실습 종료 시 잔여 리소스도 확인한다. 실습이 어려우면 우선 구성도·정책 읽기·장애 시나리오로 연습하되 실제 조작 경험과 구분한다.

## 자료와 시험 범위

현재 목표는 2026-11-17부터 제공되는 SAP-C03. 공식 가이드의 영역은 클라우드 기반 설계 25%, 보안·컴플라이언스·거버넌스 25%, 비용 최적화 15%, 복원력·이전·비즈니스 연속성 15%, 운영 우수성·자동화 20%다. 주차들은 여러 영역을 함께 다룬다. 영역별 취약도는 점검 때 따로 추적한다.

우선 공식 가이드와 Skill Builder를 사용하고, 별도 유료 강의·모의고사는 기초 점검 뒤 필요할 때 고른다. 자료별 무료/유료 제공 범위는 수강 전에 확인한다. 실제 유출 시험문제는 사용하지 않는다. 8주마다, 그리고 시험 예약 전 최신 가이드와 변경 사항을 다시 확인한다.
