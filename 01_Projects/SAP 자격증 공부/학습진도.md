## 확인한 이해

- AZ 장애에 대비하려면 서버를 여러 AZ에 분산해야 하는 이유를 정확히 설명함.
- 리전과 AZ의 관계를 정확히 설명함.
- 공동 책임 모델 3문항 모두 정답. EC2 게스트 운영체제의 패치는 고객 책임이며, 모든 AWS 서비스의 패치를 고객이 맡는 것은 아님을 보충 설명. 1주차 전체는 진행 중.

- 관리형 서비스 적용 문제 2/2 정답. S3 기반 OS는 AWS가 관리하며, 데이터 접근 대상·범위를 결정하고 권한을 설정하는 것은 고객 책임임을 보충 설명.
