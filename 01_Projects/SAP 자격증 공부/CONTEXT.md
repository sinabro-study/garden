# AWS SAP 학습 이어가기 컨텍스트

최종 갱신: 2026-10-31 (Asia/Seoul)

이 문서는 다른 컴퓨터나 새 대화에서 기존 수업을 이어가기 위한 인계 문서다. 현재 학습 상태는 `학습진도.md`, 전체 일정은 `학습계획.md`와 함께 확인한다. 기록이 달라지면 최신 날짜의 실제 답변·평가 기록을 우선하고, 확인되지 않은 완료나 점수를 추정하지 않는다.

## 1. 학습자와 목표

- 목표: AWS Certified Solutions Architect – Professional 취득.
- 출발점: AWS 기초부터 시작.
- 공부 시간: 주 5시간.
- 계획: 우선 32주/160시간. 이해도에 따라 조정하며 합격 보장 기간은 아니다.
- 시험일: 미정. 시작 당시 예상 준비도 평가 시점은 2027년 6월 전후.
- 현재 목표 시험 버전: SAP-C03. 다음 담당자는 최신 공식 가이드를 확인하고 변경이 있다면 계획을 조정한다.
- 한국어로 설명하고, 새로운 용어는 쉬운 정의와 예시를 먼저 제공한다.
- 문서 작성 선호(2026-10-31): 문장마다 줄을 나누고 불필요한 쉼표를 제거한다. 같은 주제의 문장은 빈 줄 없이 이어 쓰며 주제가 바뀌면 문단을 나눈다. 향후 수업 자료에도 적용한다.
- 지금까지 실제 AWS 리소스 생성이나 계정 조작은 진행하지 않았다.

## 2. 파일 위치와 다른 컴퓨터에서 사용하기

이 문서가 있는 폴더가 학습 작업의 기준이다.

- 저장소 내 상대 경로: `01_Projects/SAP 자격증 공부/`
- 현재 컴퓨터의 저장소: `/Users/duho_lee/Develop/Personal/garden`
- 이전 위치: `/Users/duho_lee/Documents/ChatGPT/AWS 자격증`

이전 위치에 사본이 남아 있어도 새 자료와 진도는 이 문서가 있는 폴더에서 관리한다. 다른 컴퓨터에서는 사용자 이름과 저장소 경로가 달라질 수 있으므로 절대 경로를 고정하지 않는다. 한글 파일명이 Unicode 정규화 방식에 따라 다르게 보일 수 있으니, 파일을 못 찾으면 폴더 목록을 확인한다.

다른 컴퓨터에서도 최신 파일을 볼 수 있도록 이 폴더 전체를 사용자의 기존 동기화 방법으로 가져와야 한다. 이 문서를 만든 것만으로 Git 커밋·푸시나 기기 간 자동 동기화가 설정된 것은 아니다. 사용자가 요청하지 않은 커밋·푸시는 진행하지 않는다.

## 4. 반드시 지킬 수업 방식

1. 먼저 해당 수업 자료 파일에 개념 설명, 예제, 확인 문제를 준비한다.
2. 자료 링크를 제공하고, 자료 범위 안에서 설명한다.
3. 사용자가 직접 답하도록 문제를 제시한다. 미응답 문제의 정답은 미리 공개하지 않는다.
4. 답변을 채점하되, 결론이 맞는 것과 이유가 정확한 것을 구분한다. 이유가 모호하면 짧게 교정한다.
5. 답변을 받은 뒤 자료에 해설을 반영하고 `학습진도.md`를 갱신한다.
6. 수업을 마치거나 다음 행동이 바뀌면 이 문서의 현재 상태도 함께 갱신한다.

사용자가 “수업 자료에 없는데”라고 지적한 이력이 있다. 새 개념을 채팅에서 먼저 가르치거나 자료에 없는 문제를 내지 않는다. 필요한 내용은 자료에 먼저 추가한다.

수업은 설명 → 예제 → 설계/확인 문제 → 채점·해설 → 복습으로 진행한다. 사용자는 “ㅇㅇ 다음”처럼 짧게 다음 단계 진행을 요청할 수 있다. 그때는 다음 자료를 준비하고 바로 수업을 진행한다.

실제 AWS 실습 전에는 사용 가능한 계정과 허용 비용을 확인하고 생성할 리소스, 예상 비용, 삭제 절차를 안내한다. 파일 작성 요청을 AWS 계정 조작의 승인으로 해석하지 않는다.

## 5. 현재 상태

- 현재 위치: 2주차 두 번째 수업 IAM 사용자·역할 및 두 정책. 확인 문제 3문항 답변 대기.
- 완료 주차: 1/32. 종합 확인 5/5와 회상 복습의 핵심 설명을 근거로 2026-10-31에 1주차 완료.
- 세 번째 수업은 2026-10-31 평가 완료: 1·2번 정답, 3번 부분 정답. 재연결과 일시적 접속 실패 설명을 보완했다.
- 폴더 이동과 이 인계 문서 작성 때문에 잠시 멈췄을 뿐, 학습을 처음부터 다시 시작할 필요는 없다.

### 확인된 점수

| 범위 | 점수 | 상태 |
|---|---|---|
| 리전과 AZ | 2/2 | 확인 완료 |
| 공동 책임 모델 | 3/3 | 정답, EC2 OS 패치 이유 보완 |
| 관리형 서비스 책임 적용 | 2/2 | 정답, 고객 데이터 권한 책임 이유 보완 |
| 확장성·탄력성 | 3/3 | 정답, AZ 장애 범위 표현 보완 |
| 두 AZ 쇼핑몰 설계 | 정답 2, 부분 정답 1 | 재연결·일시적 실패 설명 보완 |
| 1주차 종합 확인 | 5/5 | 통과, EC2 책임 이유·드라이버 지원 범위 표현 보완 |
| 계정·IAM 기초 | 3/3 | 최소 권한·인증/인가·역할 선택 확인, 임시 자격 증명 탈취 가능성 보완 |

기초 확인 점수와 별도로 종합 확인은 새로운 5문항 평가 결과다. 실전 모의시험 결과로 해석하지 않는다. 마지막 회상 복습까지 확인하고 1주차를 완료했다.

### 이미 보충 설명한 사항

- Multi-AZ는 AZ 단위 장애에 대비하는 구성이다. 리전 전체 장애 대비는 별도로 설계한다.
- 단일 AZ 장애가 모든 AWS 서비스의 중단을 뜻하지는 않는다. 해당 AZ에 의존하는 구성요소가 영향을 받을 수 있다.
- EC2 게스트 운영체제 패치는 고객 책임이다. 모든 AWS 서비스의 기반 OS를 고객이 패치하는 것은 아니다.
- S3의 기반 OS는 AWS가 관리한다. 누가 회사 파일에 접근할지 결정하고 설정하는 일은 고객 책임이다.
- 서버 대수 확대, 수요에 따른 확대·축소, 장애 격리는 관련이 있지만 구분하여 판단한다.

## 6. 바로 이어갈 문제

[2주차 첫 수업 자료](06_계정과_IAM_기초.md)의 확인 문제는 2026-10-31에 3/3으로 평가 완료했다. 최소 권한 원칙과 인증·인가 구분 및 EC2 역할 선택을 정확히 설명했다. “임시 자격 권한”을 “임시 자격 증명”으로 다듬고 임시 자격 증명도 유효 기간 동안 탈취 사용될 수 있음을 보완했다. [두 번째 수업 자료](07_IAM_사용자와_역할_두_정책.md)를 준비해 제공했다. 다음은 해당 자료의 확인 문제 3개를 채점하는 것이다. 아직 사용자 답변은 없다. 문제는 읽기 역할의 삭제 가능 여부와 EC2를 허용하지 않은 신뢰 정책의 수정 및 사람도 역할을 사용할 수 있는지 묻는다. 정답은 답변 전 공개하지 않는다. 자료에 STS·세션·인스턴스 프로파일의 쉬운 정의와 정책 판단의 가정을 포함했다. 신뢰 정책 역시 역할을 맡는 동작에 대한 인가라는 점을 설명했다.

1주차 완료 근거: 새로운 종합 확인 5/5 통과 및 마지막 회상 복습 핵심 설명 완료. EC2 고객 관리 범위의 이유는 정확히 재확인했다. ALB는 정상 AZ가 아니라 정상 웹 서버로 요청을 전달하고, Multi-AZ는 AZ 장애 자체를 막는 것이 아니라 장애 시 서비스를 이어갈 수 있도록 대비한다는 표현을 보완했다. 회상 1번에는 재연결 설명이 빠졌지만 직전 종합 확인 5번에서 이미 설명했으므로 함께 반영했다. 과거 부분 정답 기록은 소급 변경하지 않는다.

2주차 첫 수업 자료는 공식 IAM 문서를 확인해 준비했으며 실제 AWS 계정 조작은 진행하지 않았다. 2주차는 아직 미완료다.

추가 요청으로 2주차 첫 자료의 MFA 절을 확장했다. 지식·소유·생체 요소와 AWS 루트/IAM 사용자의 패스키·보안 키·가상 인증 앱·하드웨어 TOTP 토큰을 설명한다. 숫자 코드 외 방식도 포함했다. 이후 확인 문제 3개 답변을 받아 3/3으로 평가했다.

## 7. 완료와 복습 기준

- 일반 주차 목표: 핵심 개념을 자기 말로 설명하고 새로운 확인 문제 5개 중 4개 이상 정답 및 선택 이유 설명.
- 부족하면 오개념 보완 후 다른 문제로 다시 확인.
- 모의시험은 처음 보는 적법한 문제를 사용하고, 실제 시험 유출 문제는 사용하지 않는다.
- 모의 정답률을 AWS 환산 점수나 합격 보장으로 표현하지 않는다.
- 공식 가이드와 변경 사항은 8주마다, 시험 예약 전에 다시 확인한다.
